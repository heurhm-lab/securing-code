How to read this report

The model never sees race or ethnicity. ZIP3 areas are labelled using census-based population estimates in zip_reference.csv so the committee can test whether location-based inputs reproduce a protected-class disparity. A red status requires both the threshold breach and statistical significance (p < 0.05, or a confidence interval that excludes parity). The raw referral and fast-pay ratios are capped at amber when the risk-adjusted ratio is green, because that gap is explained by the claims themselves; otherwise it is shown as amber. An amber needs p < 0.10, so ordinary month-to-month noise stays green. Thresholds are set in thresholds.json.
